# Free & Open Source Asset Guide for "The Game"
## Curated by Mehdi Lakhouane

A hand-picked collection of free, open-source assets for building a 2D Top-Down Fantasy RPG.
Every entry below has been verified for license compatibility.

---

## 1. CHARACTER SPRITE SHEETS

### Superpowers Asset Packs — Medieval Fantasy
- **Link:** https://github.com/sparklinlabs/superpowers-asset-packs
- **License:** CC0 (public domain — no attribution required)
- **Art Style:** 16-bit cute pixel art, vibrant colours
- **What you get:** 4-directional character sprites, NPCs, monsters, background elements, HUD pieces
- **Asset path:** `medieval-fantasy/` — sub-folders include `character/`, `background-elements/`, `hud/`
- **Also check:** `rpg-battle-system/` folder for turn-based battle sprites

### Universal LPC Spritesheet Character Generator
- **Link:** https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator
- **Live Generator:** https://liberatedpixelcup.github.io/Universal-LPC-Spritesheet-Character-Generator/
- **License:** Mixed CC-BY-SA 3.0 / CC0 / GPL 3.0 (per-asset — download the CREDITS.csv)
- **Art Style:** 16-bit top-down RPG (think SNES-era)
- **What you get:** Fully customisable character sheets with walk, slash, thrust, spellcast, shoot, hurt, climb, run, and jump animations. Male, female, child, and elderly bases.
- **Asset path:** Use the live generator to export a PNG sheet, or browse `spritesheets/` in the repo

### Mozilla BrowserQuest
- **Link:** https://github.com/mozilla/BrowserQuest
- **License:** CC-BY-SA 3.0 (content), MPL 2.0 (code)
- **Art Style:** 16-bit retro MMORPG, bright and clean
- **What you get:** Hundreds of fantasy character sprites, NPC sprites, enemy sprites, item icons
- **Asset path:** `client/img/` — sprites are individual PNGs; `client/sprites/` contains JSON animation definitions

### Ninja Adventure Asset Pack (by Pixel-boy)
- **Link:** https://pixel-boy.itch.io/ninja-adventure-asset-pack
- **GitHub (Godot project):** https://github.com/pixel-boy/NinjaAdventure
- **License:** CC0 (public domain)
- **Art Style:** 16-bit top-down, colourful, Zelda-like
- **What you get:** 50+ characters with animations, 30+ monsters, 9 bosses, facesets, tilesets, 100+ SFX, 37 music tracks, UI elements, items
- **Asset path:** After download, assets are in `Ninja Adventure/` — sub-folders for `Actors/`, `Backgrounds/`, `Items/`, `Musics/`, `Sounds/`, `HUD/`
- **Note:** This is the same pack used in the Clear Code Zelda tutorial

## 2. ENVIRONMENTAL TILESETS

### Clear Code — Zelda Tutorial Assets
- **Link:** https://github.com/clear-code-projects/Zelda
- **License:** CC0 (assets by Pixel-boy / AAA from Ninja Adventure pack)
- **Art Style:** 16-bit Zelda-style top-down
- **What you get:** Ready-to-use tilemap with grass, trees, bushes, houses, dungeon walls. Pre-built level CSVs for Tiled.
- **Asset path:** `graphics/` — sub-folders for `tilemap/`, `monsters/`, `particles/`, `weapons/`, `player/`

### Kenney — Roguelike/RPG Pack
- **Link:** https://kenney.nl/assets/roguelike-rpg-pack
- **License:** CC0 (public domain)
- **Art Style:** Clean 16x16 pixel art, consistent palette
- **What you get:** 1,700+ tiles/sprites — dungeon floors, walls, doors, characters, items, UI elements
- **Asset path:** Download ZIP → `Spritesheet/` for atlas, `Tiles/` for individual PNGs

### Kenney — RPG Base + RPG Urban Pack
- **Link (Base):** https://kenney.nl/assets/rpg-base
- **Link (Urban):** https://kenney.nl/assets/rpg-urban-pack
- **License:** CC0
- **Art Style:** Clean vector-ish 2D, 16x16 base
- **What you get:** 230+ base RPG tiles (terrain, nature, buildings) + 480 urban tiles (houses, shops, roads)

### 0x72 — 16x16 Dungeon Tileset
- **Link:** https://0x72.itch.io/16x16-dungeon-tileset
- **License:** CC0
- **Art Style:** 8-bit / NES-era pixel art
- **What you get:** Dungeon walls, floors, doors, torches, treasure chests, enemies, characters — all in a consistent 16x16 grid

### OpenGameArt — 32x32 Fantasy Tileset
- **Link:** https://opengameart.org/content/32x32-fantasy-tileset
- **License:** CC-BY-SA 3.0
- **Art Style:** 16-bit SNES-style
- **What you get:** Grass, water, mountains, trees, buildings — 32x32 tiles ready for Tiled

### finalbossblues — Open RPG Fantasy Tilesets (OpenRTP)
- **Link:** https://finalbossblues.itch.io/openrtp-tiles
- **License:** CC0
- **Art Style:** 16-bit RPG Maker-style
- **What you get:** Exterior and interior tiles — forests, villages, castles, caves

## RECOMMENDED "STARTER KIT" COMBO

For the most cohesive Zelda-like look with minimal mixing, use:

| Category   | Source                    | Why                                              |
|------------|---------------------------|--------------------------------------------------|
| Characters | Ninja Adventure Pack      | 50+ animated characters, Zelda-style, CC0        |
| Tiles      | Ninja Adventure Pack      | Matching tileset with auto-tiling, CC0           |
| Enemies    | Ninja Adventure Pack      | 30+ monsters + 9 bosses with animations, CC0     |
| UI/HUD     | Ninja Adventure + Kenney  | Heart icons from Ninja, panels from Kenney UI    |
| SFX        | Ninja Adventure + Kenney  | 100+ SFX from Ninja, 50 more from Kenney RPG    |
| Music      | Ninja Adventure Pack      | 37 loopable fantasy tracks, CC0                  |

This gives you a complete, visually consistent game — all CC0, all free.
